# 6.3.2

## Package Control installation fix

Package Control now installs OpenAI Completion as an unpacked directory. This
fixes `ModuleNotFoundError: No module named 'OpenAI completion.plugins.vendor'`
when Sublime loads the shared chat libraries from a packaged installation.

Restart Sublime Text after updating if it still reports an import error. This
clears cached import paths from the previous packaged installation.

This patch keeps the Python 3.14 runtime and requires Sublime Text build 4205
or newer. Older builds remain on the Python 3.8-compatible 6.1.0 release line.
