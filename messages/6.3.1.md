# 6.3.1

## Cache folder handling

- Choosing Cancel when asked to create a missing cache folder now stops the action cleanly.
- Opening a view no longer prompts to create the cache folder. The prompt appears when an action needs to write to the cache.
- If no assistant is configured and no cached model is available, the plugin reports the missing configuration instead of raising an indexing error.

This patch keeps the Python 3.14 runtime and requires Sublime Text build 4205 or newer. Older builds remain on the Python 3.8-compatible 6.1.0 release line.
